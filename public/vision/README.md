MediaPipe Selfie Segmenter float16 v1, modelo oficial Google.
Os binários locais são preparados por `npm run prepare:vision` (também executado após instalação).
Runtime: @mediapipe/tasks-vision, Apache-2.0. Modelo e origem: https://developers.google.com/edge/mediapipe/solutions/vision/image_segmenter
O runtime e o modelo são usados somente no computador do usuário; nenhuma mídia é enviada à rede.
